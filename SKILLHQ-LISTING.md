## Short description

Free real-estate workflow foundation that verifies CRM/market connector readiness, separates persistent client context from transient MLS facts, and prevents invented current-market claims.

## Marketplace description

Agent OS Lite gives ChatGPT, Claude, Codex, and compatible Agent Skills environments two foundational operating rules for real-estate workflows: check what CRM/current-market capabilities are actually available before promising results, and keep persistent client relationship context separate from transient MLS/current-market data.

It is designed for agents experimenting with AI-assisted CRM + market workflows who need a safer, repeatable starting point before running buyer, seller, or follow-up automations.

Agent OS Lite does not provide MLS access, MLS credentials, IDX/VOW rights, CRM subscriptions, connector credentials, brokerage approval, or association approval. It works only with systems and data the user is separately authorized to access.
